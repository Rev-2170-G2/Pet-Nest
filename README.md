# 🐾 Pet Nest  
**"Connecting Pet Lovers and Pet Talent."**

Pet Nest is a full-stack platform that connects **pet owners** with **event organizers** seeking animal services. Users can create profiles for their pets, offer them for events, browse opportunities, and connect through a unified, interactive community.

## 🐶 About  

**Pet Nest** bridges the gap between animal enthusiasts and event planners.  
It provides tools for:
- Managing pet profiles  
- Browsing available pets and events  
- Requesting or offering participation  
- Viewing interactive maps of nearby listings  

---

## 👥 User Roles & Features  

### 🐾 **Guest**
- Browse all pets and approved events  
- View map showing pets and events by location  
- View extended details for pets or events  

### 👤 **Nester (Registered User)**
- Secure authentication system (JWT)  
- View personal profile with pets, events, and offers  
- Add, update, or delete pets  
- Create, edit, or delete events  
- Send or accept event participation offers  
- Leave and read reviews on pet profiles  

### 🛠️ **Admin**
- Admin accounts can only be created by existing admins  
- Access to an **Admin Dashboard**  
- Approve or deny event listings  
- Manage all users, events, and pet data
